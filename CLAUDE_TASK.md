# Завдання для Claude Code: сайт YEVCHENKO COSMETOLOGY

Збудуй з нуля сайт косметологічного кабінету за технічним завданням нижче (розділ «ТЗ»). Працюй у поточній директорії.

## Стек і підхід
- **Astro** (статичний сайт) + **Tailwind CSS**. Мінімум JS, швидке завантаження.
- Весь контент (тексти, послуги, бренди, контакти, посилання на месенджери, фото) винеси в **content collections / JSON / Markdown** у `src/content/`, щоб власниця могла змінювати його без правок у коді. Додай **Decap CMS** (`/admin`) як простий редактор контенту, або опиши в README, як редагувати файли.
- Усі контакти й посилання (Instagram, Telegram, телефон, адреса, карта, графік) — в одному файлі налаштувань `src/content/site.json` з чіткими плейсхолдерами `TODO`.
- Мова сайту — українська.

## Сторінки
`/` Головна, `/pro-mene`, `/posluhy` + окрема сторінка для кожної з 11 послуг (`/posluhy/[slug]`), `/biologique-recherche`, `/dmk`, `/domashnii-dohliad`, `/kontakty`.

## Обов'язково
- Адаптивність: спершу мобільна версія, далі планшет і десктоп.
- Помітна кнопка «Записатися» (Telegram / Instagram Direct) у хедері, на головній і на кожній сторінці послуги. На мобільному — плаваюча кнопка запису.
- SEO: унікальні `title` і `meta description`, зрозумілі URL, `alt` для зображень, `sitemap.xml`, Open Graph.
- Стиль: мінімалізм, теплі молочні, бежеві, світло-сірі відтінки; елегантна шрифтова пара (наприклад, Cormorant Garamond для заголовків + Inter / Manrope для тексту, з кирилицею); багато вільного простору.
- Зображення — тимчасові плейсхолдери з вільною ліцензією (Unsplash тощо) або нейтральні заглушки, легко замінні. Не видавати чужі фото за реальний кабінет чи спеціалістку.
- **Не вигадуй** ціни, тривалість, показання, протоколи, дипломи, сертифікати чи гарантії результату. Де даних немає — постав помітний плейсхолдер `[уточнити у спеціаліста]`.
- Без кошика, онлайн-оплати та онлайн-календаря.

## Порядок роботи
1. Створи проєкт, структуру контенту й базовий layout (хедер, футер, кнопка запису).
2. Зроби головну, потім решту сторінок.
3. Напиши чорнові тексти за ТЗ у спокійному, професійному тоні без тиску.
4. Запусти `npm run build`, переконайся, що все збирається без помилок, перевір мобільну версію.
5. Додай `README.md`: як запустити, як редагувати контент, що ще треба заповнити (список TODO), як задеплоїти (Netlify / Vercel / Cloudflare Pages).

Наприкінці коротко звітуй: що зроблено, як запустити локально, список відкритих TODO.
